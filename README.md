# CodeAlpha Python Projects

This repository contains Python projects completed as part of the CodeAlpha Python Programming Internship. These projects demonstrate fundamental Python concepts, problem-solving skills, automation, and file handling.

## Projects Included

### 1. Hangman Game
A text-based Hangman game where the player guesses a randomly selected word one letter at a time.

#### Features
- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect attempts
- Win/Loss detection
- Console-based interface

#### Concepts Used
- random module
- while loop
- if-else statements
- strings
- lists

---

### 2. Stock Portfolio Tracker
A simple stock portfolio tracker that calculates the total investment value based on user-entered stock quantities and predefined stock prices.

#### Features
- User input for stock symbols and quantities
- Portfolio value calculation
- Investment summary display
- Report generation using file handling

#### Concepts Used
- Dictionaries
- Input/Output
- Basic arithmetic
- File handling

---

### 3. Task Automation Script (Email Extractor)
A Python automation script that extracts email addresses from a text file and saves them to a separate output file.

#### Features
- Reads data from a text file
- Extracts email addresses using Regular Expressions
- Removes duplicate email addresses
- Saves results to an output file

#### Concepts Used
- Regular Expressions (re)
- File handling
- Lists
- Exception handling

---

## Technologies Used

- Python 3
- Standard Python Libraries:
  - random
  - re
  - os
  - file handling
